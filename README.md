# Portfólio React + Sass

Protótipo de portfólio pessoal desenvolvido para praticar componentização em React e organização de estilos com Sass.

## Visão geral

A interface reúne apresentação profissional, contatos, tecnologias e uma área de projetos. O layout é dividido em componentes reutilizáveis e usa ícones para apoiar a navegação e a leitura das informações.

## Recursos

- Sidebar com informações de contato e redes sociais;
- seção de apresentação;
- grade de tecnologias;
- cards de projetos;
- estilos organizados em arquivos Sass;
- layout responsivo;
- desenvolvimento e build com Vite.

## Tecnologias

- React 18
- JavaScript
- Sass
- React Icons
- Vite

## Como executar

Requisitos: Node.js e npm.

```bash
git clone https://github.com/felipeand-dev/react-sass.git
cd react-sass
npm install
npm run dev
```

Abra o endereço informado pelo Vite no terminal.

## Scripts

```bash
npm run dev      # ambiente de desenvolvimento
npm run build    # build de produção
npm run lint     # análise estática
npm run preview  # prévia do build
```

## Status

Projeto de estudo e protótipo visual. Antes de utilizá-lo como portfólio atual, os links, textos e projetos exibidos devem ser revisados.
